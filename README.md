# Heutagogy Workshop — Interactive Experience Space

An interactive Hebrew (RTL) web page for a heutagogy (self-directed learning)
workshop for lecturers. Instead of a static worksheet, participants browse a
menu of seven experiences, **edit** ready-made prompts directly in the page,
and **copy** them with one click into their preferred AI tool
(ChatGPT, Claude, Gemini, etc.).

## Features
- Single self-contained file — `index.html` (no build step, no dependencies).
- Seven experiences, each opening in a clean dialog.
- Prompts live in editable text boxes; one-click copy includes any edits.
- Faithful to the original worksheet — every text preserved verbatim.
- Accessible per Israeli Standard SI 5568 / WCAG 2.0 AA (skip link, keyboard
  navigation, focus styles, reduced-motion, accessibility statement).

## Usage
Open `index.html` in any modern browser, or visit the published GitHub Pages
link.
